# Podcasts — The GenAI Evolution Atlas

Two audio episodes per week, generated with **NotebookLM** (Deep Dive format,
Long length) from the week's [`../digests/`](../digests/) and prepared for
upload to the show **The GenAI Evolution Atlas** on RSS.com. Full procedure:
[`../automation/podcast_playbook.md`](../automation/podcast_playbook.md).

- **Wednesday — Deep Dive.** An in-depth episode on the single most important
  innovation of the past week (usually 1 article, at most 3 when there are
  genuinely multiple critical items). Steered by
  [`../automation/podcast_deepdive_prompt.md`](../automation/podcast_deepdive_prompt.md).
- **Friday — News Roundup.** A broad, quick tour of everything worth calling out
  that week, then synthesis, opinion, and a look ahead. Steered by
  [`../automation/podcast_roundup_prompt.md`](../automation/podcast_roundup_prompt.md).

Both are **Season 2** and share one running episode counter (Wed = next odd,
Fri = next even, in generation order), starting at E01.

## What's in this directory

| Path | What it is |
|------|-----------|
| [`episodes.json`](episodes.json) | The manifest: season, the `next_episode` counter, and one record per episode (title, description, audio path, public URL, cover, sources, RSS status). |
| `S<season>E<NN>-<YYYY-MM-DD>-<type>.m4a` | The generated audio, one file per episode. |
| per-episode `*.md` | The finished title + description (the copy that goes to RSS.com), kept next to the audio for review. |

Episode covers live under
[`../docs/thumbnails/podcast/`](../docs/thumbnails/podcast/) (served by GitHub
Pages), generated by
[`../artifact/thumbnails/podcast_thumbs.py`](../artifact/thumbnails/podcast_thumbs.py).

## Public URLs (for the RSS.com upload)

RSS.com's API ingests audio from a public download URL. Committed files here are
reachable at:

```
https://raw.githubusercontent.com/peterlcy1992/genai_learning_repository/main/podcasts/<file>.m4a
```

(GitHub Pages serves this repo from `/docs`, so root-level `podcasts/*.m4a` are
*not* on the Pages domain — the `raw.githubusercontent.com` URL above is the one
the uploader uses.)

## Review-before-publish

Episodes are **never auto-published.** The automation produces the audio, the
title/description, and the cover, and (when configured) creates the RSS.com
episode as an **unpublished draft**. The owner reviews it on RSS.com and presses
publish. See the playbook for the exact hand-off.

## A note on size

Audio files are large (~30–45 MB each, ~2/week). If repository size becomes a
concern, switch to keeping only the current week's files, or host the audio as
GitHub release assets instead of committing them — the RSS.com uploader only
needs a public URL, wherever it points.
