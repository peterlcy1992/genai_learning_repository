# digests/

One file per day: the **full, formatted daily brief** — the same content the
daily email summarizes, but complete and nicely rendered on GitHub.

- Files are named `YYYY-MM-DD.md`.
- Each contains: your current learning stage + next action, every new item the
  automation logged that day (with links and stage tie-backs), and an "if you
  read one thing today" pick.

## Why this exists
The daily email is a fixed notification template — it shows a short summary and
an **Open session** button, so the full brief can't be inlined into the email
body. Instead, the email's summary **links directly to that day's digest file
here**, so you're one click from the complete, rendered brief without opening a
session.

The rolling, all-days-in-one log lives in
[`../updates/latest.md`](../updates/latest.md); these per-day digests are the
reader-friendly slices the email points at.
