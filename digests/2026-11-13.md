## Today's highlights

### MNN-Pocket-0.3B Technical Report
- **Type:** paper / model release
- **Link:** https://arxiv.org/abs/2611.12311
- **Why it matters:** A compact model of about 300M parameters with open weights, built for on-device use with context windows of up to 32K tokens. The report says it reaches up to 466 tokens/s on an iPad Pro M5. It shows how capable tiny edge models have become. (via web search; page not fetched)
- **Relates to:** Stage 4 — efficiency (small models, on-device inference)

### Multi-agent LLM systems: when reasoning about other agents makes aggregated judgments worse
- **Type:** paper
- **Link:** https://arxiv.org/abs/2611.08971
- **Why it matters:** This paper studies multi-agent LLM setups that combine several agents' judgments. It finds that having agents reason about each other can introduce failures instead of helping. Only an aggregator snippet surfaced, so the exact title and method are unverified. (via web search; page not fetched)
- **Relates to:** Stage 7 — agents & applications (multi-agent systems)

### Agents that fail to learn from user corrections across sessions
- **Type:** paper
- **Link:** https://arxiv.org/abs/2611.08644
- **Why it matters:** This paper targets a familiar agent failure: you correct the agent once and it repeats the mistake in the next session. That makes it a good companion to the recent agent-memory papers in the log. Only an aggregator snippet surfaced, so the title and approach are unverified. (via web search; page not fetched)
- **Relates to:** Stage 7 — agents & applications (memory)
